# Segmenta Studio

Plataforma de grabación y edición de video: cámara cloud, teleprompter, portafolios, selección de tomas, estilos y render vertical.

La aplicación desplegable en Vercel está en [`apps/studio-web`](apps/studio-web/README.md). Las [14 skills de edición](apps/studio-web/skills/README.md) tienen instrucciones propias y un catálogo configurable en la aplicación.

El motor actual ejecuta decisiones medibles con FFmpeg. El puente de Claude/Gemini, la transcripción de voz y la extracción automática de clips siguen en desarrollo; su estado está indicado dentro de cada skill.
