# Edición y encuadre

Entrada: `zoomPercent` de 0 a 10 y `framing` igual a `fill` o `fit`. Salida: `style_snapshot.execution.zoomPercent` y `.framing`. El renderer escala o rellena el lienzo 1080 × 1920 y aplica el acercamiento configurado.
