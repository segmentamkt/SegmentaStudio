# Narrativa

Entrada: libreto, orden de escenas, objetivo y estructura deseada. Salida actual: decisión editorial en `skill_manifest`; el render mantiene el orden de escenas aprobadas. Las opciones “gancho primero” o “problema y solución” aún no reordenan tomas automáticamente.
