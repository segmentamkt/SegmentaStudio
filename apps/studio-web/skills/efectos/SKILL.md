# Efectos visuales

Entrada: libreto, título y contexto visual. El ajuste `titleCards` controla `style_snapshot.execution.titleCards` en el contrato. El renderer dibuja el rótulo inicial cuando las superposiciones también están activas. Mapas, iconos y cifras gráficas necesitan activos y lógica de sincronización adicionales.
