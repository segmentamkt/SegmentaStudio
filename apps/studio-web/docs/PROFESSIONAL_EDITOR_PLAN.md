# Camino al editor profesional de Segmenta Studio

Este documento fija entregables comprobables. Una función solo se marca como lista cuando puede verse en la vista previa o en el MP4 final, según corresponda.

| Etapa | Estado | Criterio para cerrar la etapa |
| --- | --- | --- |
| 1. Orientación y entrada | En marcha | Una persona nueva puede subir videos, encontrar el libreto, preparar y localizar el resultado sin ayuda externa. Pingüino guía y ruta visual publicados; falta una prueba de uso con personas nuevas. |
| 2. Montaje por libreto | Parcial | Transcripción real por toma, coincidencia con el libreto, propuesta de orden y cortes revisables antes de renderizar. Hoy el orden depende del texto aportado por la persona. |
| 3. Edición manual completa | Parcial | Línea de tiempo multipista con arrastre, audio visible, capas de imagen, texto, efectos y transiciones editables con vista previa fiel. Hoy funcionan recorte, división, duplicación, orden, velocidad, volumen y color por segmento. |
| 4. Recursos profesionales | Pendiente | Biblioteca de música y efectos con licencia clara, imágenes y B-roll propios o generados, búsqueda y colocación temporal por escena. |
| 5. Render confiable y clips largos | Parcial | Trabajos durables, progreso verificable, recuperación de fallos, revisión visual/audio y exportación de videos largos y clips derivados. Hoy el render cloud admite 12 segmentos y 2 minutos. |
| 6. Dirección conversacional | Parcial | El pingüino entiende instrucciones sobre el proyecto, propone cambios concretos y solicita aprobación antes de modificar el montaje. Hoy es una guía contextual local sin modelo generativo conectado. |

## Reglas de producto

1. La persona ve la toma original, la edición propuesta y el MP4 exportado como estados distintos.
2. Cada recurso del proyecto muestra origen, licencia y ubicación en la línea de tiempo.
3. Ningún control se etiqueta como disponible si no altera un resultado verificable.
4. Las decisiones automáticas se pueden revisar, deshacer y reemplazar manualmente.
5. La vista móvil prioriza revisión, aprobación y ajustes simples; la edición multipista puede aprovechar pantallas grandes.

## Próximo corte funcional

Implementar transcripción automática con marcas de tiempo y comparación con el libreto, seguida por una línea de tiempo con forma de onda y arrastre. Esto desbloquea orden cronológico, subtítulos precisos y cortes guiados por el habla sin pedir a cada persona que escriba la transcripción manualmente.
