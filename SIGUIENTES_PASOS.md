# Siguientes pasos

La primera versión funcional ya permite cargar, editar, reproducir y conservar videos reales sin API.

Mejoras opcionales, no necesarias para usar el flujo actual:

1. Instalar FFmpeg si se desea detección automática de silencios y cortes basados en audio.
2. Elegir e instalar un transcriptor completamente local si se desean subtítulos automáticos sin enviar el video a terceros.
3. Proporcionar pares de videos originales/editados para calibrar el estilo de Kiko con evidencia real.
4. Autorizar conectores oficiales de redes si se desea investigación automática de tendencias.
5. Configurar un LaunchAgent solo si se necesita trabajo nocturno y se acepta mantener el Mac despierto.

No se propone configurar APIs ni claves de proveedores: contradice la regla vigente del usuario.
